# Markガイド

そのまま編集できる短いツアーです。このページはごく普通のMarkドキュメントです。「別名で保存」を選ばない限り、ファイルに書き込まれることはありません。

## エージェントを接続

これをClaude Code、Codex、Cursorなど任意のエージェントに一度だけ渡してください。指示ファイル（例: `CLAUDE.md` や `AGENTS.md`）またはチャットにそのまま貼り付けます。コピーはブロックのボタンから。

```text
@@AGENT_PROMPT@@
```

1. **エージェントがファイルを書く** — 長い計画やレポートは `.md` ファイルになり、Markで開きます。
2. **Markが追従する** — 保存のたびにページが再読み込みされ、位置は保たれます。
3. **あなたが形にする** — 完成したページを編集します。手順を直し、メモを足し、誤りを削る。
4. **エージェントが読み返す** — エージェントはファイルを再読み込みし、あなたの編集が次の指示になります。

## 試してみよう: テーブル

テーブルはプレーンテキストで、入力しながら整形されます。カーソルを中に置けばツールバーから行を増減できます。

| 機能 | ショートカット |
| --- | --- |
| 分割表示 | ⌘/Ctrl+Alt+\ |
| 差分 | ⌘/Ctrl+D |

## 試してみよう: コールアウト

コールアウトは注記を目立たせます。引用の1行目に `> [!TIP]` と入力します。

> [!TIP]
> 5種類: NOTE、TIP、IMPORTANT、WARNING、CAUTION。

## 試してみよう: Mermaidダイアグラム

ダイアグラムは編集しながら描画されます。

```mermaid
graph LR
  A[エージェントが書く] --> B[Markが再読み込み]
  B --> C[あなたが編集]
  C --> A
```

## 試してみよう: 数式

`$$` ブロックはKaTeXで描画されます。

$$
e^{i\pi} + 1 = 0
$$

## 試してみよう: 分割表示

⌘/Ctrl+Alt+\ でソースとプレビューを並べて表示します。もう一度押すと閉じます。

## 試してみよう: 構造化テキストとしてコピー

編集 › 構造化テキストとしてコピー は、箇条書き・リンク・表を保ったままきれいなテキストでコピーします。そのままチャットに貼れます。

## 試してみよう: 差分

⌘/Ctrl+D で差分表示を切り替え、最後の保存以降の変更を確認できます。

## 試してみよう: ズーム

⌘/Ctrl+= 拡大、⌘/Ctrl+- 縮小、⌘/Ctrl+0 で100%に戻ります。

## 試してみよう: フルスクリーンビューア

ダイアグラムを ⌘/Ctrl+クリック、またはダイアグラムやテーブルの ⤢ を押すとフルスクリーンで開きます。中でズーム、Escで閉じます。
