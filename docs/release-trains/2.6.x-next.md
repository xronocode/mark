### FIX-009

Separate cold-start session restoration from recovery of tabs closed during the current run.

- **Reported:** owner, 2026-10-20 — close the open tabs, click "Last session" on the welcome screen: nothing happens (the row showed a mount-time capture the session autosave had already emptied).
- **Owner decision (2026-10-20, train record):** a "Restore last session on launch" preference (default on; C-69 T-002 already shipped it); with it off, the welcome screen exposes "Last session" as an explicit cold-start action that must reflect a real restorable prior-session snapshot and never silently no-op. Current-run recovery is a separate session-scoped "Recently closed" history: a count-badged button beside the tab strip's +, a popover reopending one entry or "Reopen all N", the same recovery prominent on the welcome screen at zero tabs, and ⇧⌘T newest-to-oldest; dedup-to-newest by pathname, consume on any open, bounded, cleared on cold launch; unsaved untitled drafts excluded; workspace-root removal untouched.
- **Implementation (PR 19, two bundles C-FIX-009-SESSION-COLD-START + C-FIX-009-RECENTLY-CLOSED, review wave 2):** the boot offer freezes the COMPLETE restorable payload (tabs, active pathname, workspace roots) and an explicit restore reopens the FROZEN payload — the live autosaved preferences are never reread on the click path (the review's P1: the autosave may legitimately have rewritten them since boot); the automatic startup path still reads preferences. Current-run recovery per the decision: store/recentlyClosed (memory-only, bound 25, dedup-to-newest), FORCE_CLOSE_TAB records pathname tabs (strip index, active flag, root), every mt::open-new-tab arrival consumes the matching entry, the strip button's popover reopens one or all (ascending strip order, the was-active entry among successful reopens re-selected; only isFile stats open; failed invokes neither counted nor selected), the welcome block recovers at zero tabs, and File › Reopen Closed Tab (Shift+Cmd/Ctrl+T) reopens newest-to-oldest with an empty-history quiet no-op.
- **Repair evidence:** unit tests/renderer/store/recently-closed.test.js (16 cases incl. directory-stat and invoke-rejection accuracy) + editor-session-coldstart.test.js (12 cases incl. the frozen-offer-after-autosave-overwrite regression), component tabs-recently-closed.test.js (7) + the recovery block in recent.test.js (5), browser tests/e2e/recently-closed.spec.ts (Chromium); V-M-011 scenario-75; locale keys in all ten catalogs (source + minified parity).
- **Train/state:** `2.6.x-next` / implemented; owner acceptance pending on a fresh artifact (P1 regression fixed in review wave 2).
