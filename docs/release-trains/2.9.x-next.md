### C-UPDATER-ROLLBACK

- Summary: one-step updater rollback. Every update snapshots the previous version and its settings first; Help › Roll Back to Mark… restores that snapshot together with the settings it had before the update, and the version being left is skipped until a newer release ships. If an update breaks startup, the same restore runs from the terminal before the UI boots (`mark --rollback`, `--yes` for scripts). A failed snapshot cancels the update; the fresh snapshot promotes only after the new version actually boots; the Windows restore verifies the previous installer's minisignature against the pinned public key (two network requests, macOS fully offline); the App Store edition exposes no rollback surface. M-068/V-M-068 route the new mt-rollback module.
- Source commit: `8dc938f3` (PR #120); archive [PR #123](https://github.com/xronocode/mark/pull/123); bundle archived with the acceptance record.
- Owner acceptance 2026-10-29: merged after a fully green run; the two-platform manual restore protocol (macOS menu + terminal crash path, Windows polygon installer) is owed as owner-executed evidence in V-M-068 and is not yet run.
