# Export

Mark can export documents to PDF and HTML formats.

## Export to PDF

**File > Export to PDF** or use the command palette.

The PDF is rendered through the system print engine with the current theme applied. Headers, tables, code blocks, and math formulas are all preserved.

## Export to HTML

**File > Export to HTML** exports a standalone HTML file with embedded styles matching the current theme.

The output is a single `.html` file that can be opened in any browser without external dependencies.
