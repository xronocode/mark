# Project Sidebar

The project sidebar shows a file tree for the currently opened folder.

## Opening a project

```sh
mark ~/my-docs/
```

Or use **File > Open Folder** (Cmd+Shift+O) from within the app.

## Toggle sidebar

Press **Cmd+B** or use **View > Toggle Sidebar** to show/hide the sidebar.

## File tree

- Click a file to open it in a new tab
- The tree is recursive and lazy-loaded
- Files are sorted alphabetically (folders first)

## Context menu

Right-click a file or folder in the tree for options:

- New file
- Rename
- Delete
- Reveal in Finder

## Sidebar width

Drag the right edge of the sidebar to resize it. The width is persisted between sessions.
