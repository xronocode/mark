## Custom CSS

You can add custom CSS overrides in **Preferences > Theme > Custom CSS**. This CSS is injected after the theme stylesheet, so you can override any variable.

Theme CSS variables follow the pattern `--editorBgColor`, `--editorColor`, `--sideBarBgColor`, etc.
