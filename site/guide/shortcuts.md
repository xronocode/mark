# Keyboard Shortcuts

## File

| Shortcut | Action |
|----------|--------|
| Cmd+N | New tab |
| Cmd+O | Open file |
| Cmd+Shift+O | Open folder |
| Cmd+S | Save |
| Cmd+Shift+S | Save as |
| Cmd+W | Close tab |
| Cmd+, | Preferences |
| Cmd+Q | Quit |

## Edit

| Shortcut | Action |
|----------|--------|
| Cmd+Z | Undo |
| Cmd+Shift+Z | Redo |
| Cmd+X | Cut |
| Cmd+C | Copy |
| Cmd+V | Paste |
| Cmd+A | Select all |
| Cmd+F | Find |
| Cmd+H | Replace |
| Cmd+G | Find next |
| Cmd+Shift+G | Find previous |
| Cmd+Shift+F | Find in folder |

## View

| Shortcut | Action |
|----------|--------|
| Cmd+B | Toggle sidebar |
| Cmd+Alt+S | Toggle source code mode |
| Cmd+D | Toggle diff view |

## Editor

| Shortcut | Action |
|----------|--------|
| Enter | New line / Find next (in search) |
| Shift+Enter | Find previous (in search) |
| Escape | Close search panel |
| Cmd+Scroll | Zoom in/out |

::: tip
On non-macOS platforms, replace **Cmd** with **Ctrl**.
:::
