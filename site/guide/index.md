# Introduction

Mark is a modern WYSIWYG Markdown editor built with [Tauri v2](https://tauri.app) and Vue 3. It renders tables, Mermaid diagrams, KaTeX math, and code blocks inline while you write.

## Why Mark?

- **Lightweight** — 11 MB binary, 61 MB RAM. No Electron, no Chromium.
- **Fast** — Opens in under a second. Native macOS app.
- **AI-native** — Live file-watcher reload, CLI preview mode, diff view. Built for workflows where agents write Markdown and you review it.
- **Full-featured** — 21 themes, project sidebar, find & replace, export to PDF/HTML, source code mode.

## Quick install

```sh
brew tap xronocode/mark && brew install --cask mark@alpha
```
