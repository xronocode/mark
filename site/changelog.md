# Changelog

User-facing changes per release. Full history on
[GitHub Releases](https://github.com/xronocode/mark/releases).

## v2.1.11-beta — 2026-09-18

- Right-click context menu in the editor: Copy, Copy as HTML, Copy as
  Plain Text, Select All — paste formatted content straight into email or
  documents.
- Retired the legacy Mark Text settings-migration prompt; fresh installs
  no longer see it.

## v2.1.10-beta — 2026-09-17

- Tab-cycling keyboard shortcuts (Ctrl/Cmd+Tab family).
- Title-bar breadcrumb no longer overlaps controls at narrow window widths.
- The active tab always stays visible when switching or resizing.

## v2.1.9-beta — 2026-08-18

- Release-infrastructure hardening.

## v2.1.8-beta — 2026-08-10

- Editor and stability fixes.

## v2.1.7-beta — 2026-08-10

- Editor and stability fixes.

## v2.1.6-beta — 2026-08-10

- Ignore stale file-change events when an external tool rewrites a
  document mid-save.

## v2.1.5-beta — 2026-08-10

- Guard boot hydration against corrupted saved state.

## v2.1.4-beta — 2026-08-10

- Restore input handling in Finder-previewed documents.

## v2.1.2-beta — 2026-08-07

- Signed in-app updater (ed25519-verified update feed); dependency notice
  refresh.
