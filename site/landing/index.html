One file, two authors.

Your agent drafts, you correct, and the file on disk carries the conversation. Nothing to paste back into a chat.

  1. The agent writes

    It saves plan.md and opens it with open -a Mark.

  2. You edit in place

    Delete a step, rewrite a paragraph, leave a note under a table. Save.

  3. The agent reads the diff

    Its next write reloads in Mark without moving your cursor.

Teach your agent once

Paste into CLAUDE.md, AGENTS.md or any system prompt your agent reads.

When you produce a plan, spec, report, or any document longer
than ~50 lines, write it to a .md file and open it for the user:

    open -a Mark <file>.md

The user reads and edits it in Mark, which reloads the file when
it changes on disk. When the file changes, read the new version:
the user left corrections inline. Treat the diff as your next
instruction.

Mark v2.1.11 downloads at 11.7 MB and idles near 61 MB with one file open. Competitor names are masked on purpose; the pattern is the point. Reproduce it with tools/benchmark/editors-bench.sh.

A small app with the right parts.

For the agent loop

Live reload
External edits appear as they land. Run mark --watch plan.md from any script.
Inline diff
⌘D compares against git HEAD or a .before file, so you see exactly what the agent changed.
Unsaved work stays safe
A reload never overwrites a tab you are still editing; you choose to save, discard or keep it.

For reading

33 themes and custom CSS
Light, dark and everything between, synced across windows.
Preview mode
Double-click a .md file in Finder and it opens read-only. Make Mark the default handler if you like.
Folders and search
A sidebar file tree, tabs, and find across a whole folder.

For your Mac

Native, not Electron
Tauri and the system WebKit view, a real menu bar, system spell-check, proper shortcuts.
Signed and notarized
Developer ID signed, notarized by Apple, updated through Homebrew.

For your files

No account, no telemetry
Nothing leaves your machine. Files stay plain Markdown on disk.
Open source
MIT licensed, built on the Muya engine from Mark Text. Read the code on GitHub.
