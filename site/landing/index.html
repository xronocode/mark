The footprint is the feature

Most Markdown editors are Electron apps — they ship an entire Chromium browser and hold hundreds of megabytes of memory just to show text. If you work with AI, your machine already runs the model, the IDE, the browser and a pile of terminals. The editor should be the cheapest window you have open.

The Agent Workflow

If you actively use AI, you don't have one window — you have a dozen: the agent, the logs, the browser, the terminals. Pasting Markdown into a browser-based converter every time is pain, and heavyweight editors tax the very machine your models run on. Mark just watches the files and renders them live; the cursor remembers its place, ready the moment the agent finishes its pass.

# Watch mode active
$ mark file.md —watch

1. Agent edits `index.md`
2. Mark detects change
3. Re-renders DOM

// While you type...
cursor: preserved

60 seconds to first render

No account, no wizard, no import. If you live in the terminal, Mark starts there too.
