Core Capabilities

Native Speed

Opens under a second with only ~61 MB RAM. A Tauri-built experience that feels lighter than air.

WYSIWYG + Source

Toggle between rich editing and raw source code instantly without losing your formatting context.

Agent Live Reload

Your AI agent edits the file on disk? Mark re-renders instantly while keeping your cursor exactly where it was.

21 Themes

From Cadmium Light to Synthwave '84. Match your environment or let the colors do the work.

Sidebar & Search

Browse your file tree, search instantly with fuzzy matching, and view diffs side-by-side.

Clean Copy

Right-click to copy as HTML or Plain Text directly from the native menu, perfect for pasting into email.

Visual Showcase

The Agent Workflow

Stop fighting the editor. Let your external tools write to disk, and watch Mark render it live. The cursor remembers its place, so you can jump back in immediately after an agent finishes a pass.

# Watch mode active
$ mark file.md —watch

1. Agent edits `index.md`
2. Mark detects change
3. Re-renders DOM
