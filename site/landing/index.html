¶ 01

Watch your agent write.

Every save on disk reloads the tab in place, keeping your scroll position, so you can follow a long pass and step in when it finishes. ⌘D shows exactly what the agent changed, against a snapshot Mark takes before every reload.

Connect your agent

The home screen connects your agent with one click — or paste this prompt into CLAUDE.md, AGENTS.md or any system prompt your agent reads.

Prompt for your agent 
When you produce a plan, spec, report, or any document longer
than ~50 lines, write it to a .md file and open it for the user:

    open -a Mark <file>.md

The user reads and edits it in Mark, which reloads the file when
it changes on disk. When the file changes, read the new version:
the user left corrections inline. Treat the diff as your next
instruction.

¶ 03

Write in the finished page.

Headings, tables, task lists, footnotes, callouts and front matter look done while you type — and the rest of the page keeps up.

  • Split View

    The raw Markdown beside the page when you need it; the rendered page itself is the editor.

  • Copy it clean

    Copy as Markdown, HTML, plain text or structured text that keeps paragraphs, bullets, links and tables readable wherever you paste them.

  • Open anything full screen

    Any diagram or wide table opens here, with zoom and pan and a sticky header for tables.

  • Print & PDF, each direct

    ⌘P opens the system print panel directly; Export to PDF writes the file through a save dialog, without the print panel — on macOS and Windows.

  • 32 themes, light and dark

    Light and dark members, one title-bar button apart — Paper, Ink, Docs, macOS and more; diagrams can follow, or pin their own look.

  • Diagrams as pictures

    Copy as image, or save as PNG or SVG in the theme’s colours — from the diagram’s corner panel, the context menu or the full-screen view.
