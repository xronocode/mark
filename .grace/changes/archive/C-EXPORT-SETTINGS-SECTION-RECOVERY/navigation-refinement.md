# Settings navigation refinement

The accepted navigation refinement of 2026-11-12 keeps General first and places Export after Markdown, before Advanced:

The order is General, Appearance, Editor, Markdown, Export, Advanced, Experimental.

Fresh Settings windows and invalid or unavailable remembered-tab storage default to General. Valid remembered selections retain their behavior. The export notification action explicitly targets Export in both new and existing Settings windows.

This refinement replaces only the first-position and fresh-default wording in the approved specification and plan. Their assertions, scopes and tasks remain unchanged.
