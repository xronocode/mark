# homebrew-mark

Homebrew tap for the **Mark** Markdown editor (private fork of [marktext/marktext](https://github.com/marktext/marktext)).

## Usage (Phase-A3 onward, after tap is published)

```sh
brew tap xronocode/mark
brew install --cask mark
```
